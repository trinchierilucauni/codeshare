# 🚀 Codeshare
Codeshare è uno spazio di condivisione del codice di configurazione delle query per la configurazione del db di [Rinnemon](https://rinnemon.vercel.app/home), un progetto realizzato da Luca Coccia e Luca Trinchieri per il corso di ***Teoria dei Sistemi Web*** della facoltà di ***Ingegneria Informatica alla Sapienza***.

## 🛠️ Tecnologie Utilizzate

**Frontend:** React + Vite

## Come avviare il progetto in locale

1. Clona il repository:
   ```bash
   git clone https://github.com/trinchierilucauni/codeshare.git

2. Installa le dipendenze
   ```bash
   npm install

3. Avvia il progetto
   ```bash
   npm run dev

**Il progetto è anche disponibile [qui](https://codeshare-wheat.vercel.app/)**
